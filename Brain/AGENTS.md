# AGENTS.md

## 适用范围

本文件适用于 `Brain/` 后端工程。根目录 `AGENTS.md` 仍然有效；若本文件与根目录规则冲突，以更具体的后端规则优先。

## 后端技术基线

- Spring Boot 3.5.x
- JDK 17
- Maven
- MyBatis-Plus
- 后端端口：`9888`
- 启动入口：`brain-admin`
- 业务模块：`brain-modules`

## 模块边界

1. `brain-admin` 放启动入口、全局配置装配和对外启动相关内容。
2. `brain-modules` 放业务模块实现。
3. `brain-common` 放跨模块通用能力，不得放具体业务流程。
4. 新增业务能力优先放入已有业务模块；确需新增模块时，先说明模块边界、依赖关系和验证方式。
5. 不得为单个页面或单个接口随意新增公共抽象。
6. 修改共享模块前，必须确认调用方和影响范围。

## 分层约定

1. Controller 只负责参数接收、权限声明、接口响应和调用服务。
2. Service 负责业务流程、事务边界、状态校验和领域规则。
3. Mapper 只负责数据库访问，不写业务判断。
4. Domain/Entity 与数据库表结构保持一致。
5. BO/DTO/VO 分别用于入参、内部传递和出参展示，不混用。
6. 字典、权限、租户、数据权限等平台能力，优先沿用项目已有写法。

## 数据库与 SQL

1. 涉及表结构、字段、索引、初始化数据、字典数据、菜单权限、角色权限或迁移脚本时，必须先定位项目现有 SQL 放置目录和命名规则，不得臆造目录。
2. 新增表必须说明：表用途、主键策略、唯一约束、索引、审计字段、逻辑删除字段、租户字段、创建/更新人字段是否需要。
3. 新增字段必须说明：字段含义、类型长度、是否可空、默认值、历史数据填充值、是否需要索引、是否影响导入导出或列表查询。
4. 修改字段必须说明兼容性影响；字段改名、类型变更、含义变更、删除字段属于高风险操作，执行前必须单独确认。
5. 新增或修改索引必须说明查询场景、组合顺序、区分度和写入性能影响。
6. 涉及字典、菜单、按钮权限、角色权限初始化数据时，必须同时说明前端权限标识、后端权限注解和菜单配置的对应关系。
7. Mapper XML 或注解 SQL 必须使用参数绑定，不得字符串拼接用户输入。
8. 分页查询必须确认分页参数、排序字段白名单、筛选条件、数据权限和租户隔离。
9. 批量更新、批量删除、状态流转、数据修复 SQL 必须先说明影响范围和回滚方式；不得默认执行。
10. 数据库变更交付时必须列出：变更脚本、影响表、兼容性、回滚方案、是否需要历史数据迁移、验证 SQL 或验证接口。

## SQL 变更前置检查

生成或修改 SQL 前，必须检查：

1. 现有表结构和同类业务表设计。
2. 实体类、Mapper、VO/BO、导入导出对象是否需要同步调整。
3. 菜单权限、按钮权限、字典数据是否需要同步初始化。
4. 是否影响已有接口、列表查询、详情查询、导出、统计和数据权限。
5. 是否需要 OpenSpec 明确数据模型、表关系和迁移策略。

## 权限与安全

1. 新增接口必须确认登录、角色、菜单按钮、数据权限和租户边界。
2. 后端权限标识必须与前端按钮、菜单权限标识一致。
3. 不得绕过现有权限注解、数据权限过滤和审计字段规则。
4. 不得输出密钥、令牌、密码、内部路径等敏感信息。
5. 导入、导出、上传、下载类接口必须检查文件类型、大小、权限和异常反馈。

## 事务与一致性

1. 涉及多表写入、状态流转、库存/额度/计数、审批流或外部调用时，必须明确事务边界。
2. 不得在循环中无界逐条写库；批量操作必须说明批大小、失败处理和回滚策略。
3. 状态流转必须校验当前状态、目标状态、操作者权限和重复提交。
4. 外部调用不得放在无法接受重试副作用的事务中；必要时说明补偿策略。
5. 并发写入场景必须说明唯一约束、乐观锁、悲观锁或幂等键策略。

## 后端验证命令

默认在 `Brain/` 目录执行；若当前位于仓库根目录，先进入 `Brain/`。

常规构建：

```bash
mvn clean package -DskipTests
```

相关测试：

```bash
mvn -pl brain-admin -am test -DskipTests=false
```

本地启动：

```bash
mvn -pl brain-admin -am spring-boot:run
```

## 交付要求

后端变更交付时说明：

1. 涉及模块、接口、表和权限点。
2. 是否影响已有 API、菜单、角色、数据权限或租户隔离。
3. 是否涉及事务、并发、批量写入或数据库迁移。
4. 已运行的 Maven 构建或测试命令。
5. 未验证项、原因和残余风险。
6. 回滚方式。
