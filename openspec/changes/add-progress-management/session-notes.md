# 通用进度管理模块会话接续

## 已确认范围

- 模块定位：通用业务进度管理模块，不与任何具体业务强绑定。
- 一期方向：出版业务场景可使用，但功能本身保持通用。
- 架构边界：后端独立 `brain-progress`，前端独立 `api/progress` 与 `views/progress`。
- 一期不接 Warm-Flow 审批，只做进度管理。
- 一期主菜单：进度驾驶舱、项目管理、我的任务、风险与阻塞。
- 一期不做自由评论；原“动态/评论”收敛为系统自动生成的操作记录。
- 项目支持多层级，项目树一期最多 3 层。
- 任意项目节点都可创建自身阶段和任务。
- 阶段和里程碑分表，阶段与里程碑为 1:N。
- 任务可直接挂项目节点，也可挂阶段；长期任务可以直接挂项目。
- 任务允许父子任务。
- 里程碑不承载任务，不参与进度权重计算。

## 阶段业务语义

- 阶段是当前项目节点下任务的业务描述维度和管理分组。
- 阶段用于表达某个项目节点内的一段计划周期或工作分组，例如需求梳理、开发实施、联调验收。
- 阶段只在所属项目节点内生效，不跨项目共享，不继承父项目阶段。
- 子项目可以维护自己的阶段；任务只能选择当前项目节点下的阶段。
- 阶段不是执行任务，不填报人工进度，不设置权重，不作为项目进度分母项。
- 如页面展示阶段进度，该值仅作为阶段列表展示值，由阶段下计入进度任务派生，不参与上卷计算。
- 阶段不做完整生命周期，只保留启用/作废语义。
- 阶段作废后不可再被新任务或新里程碑选择；已挂靠该阶段的任务和里程碑保留历史归属。
- 阶段作废不影响任务状态、任务进度、项目进度；作废需要原因和二次确认，并记录操作记录。

## 进度与权重

- 只有叶子任务产生人工进度。
- 父任务是汇总容器，不人工产生进度。
- 阶段不再作为进度汇总容器参与项目进度计算；阶段只是任务归属维度。
- 项目节点进度不再采用“直属子项目、直属阶段、直属任务统一汇总池”旧口径。
- 父子项目进度是否汇总、子项目是否设置权重、项目进度如何计算，后续继续确认。
- 父任务进度来自计入进度的直接子任务。
- 叶子任务人工进度允许 `0` 到 `100` 的整数。
- 任务默认计入进度，可通过 `include_progress` 整数枚举控制是否计入。
- `include_progress = 不计入`、已取消、已作废、已逻辑删除任务不进入进度分母。
- 任务权重是相对系数，不要求合计 `100`。
- 任务权重字段只允许非负整数；`0` 表示自动权重，正整数表示显式权重。
- 同级存在显式权重时，自动权重按同级显式权重平均值补齐。
- 同级全部自动权重时，全部等权。
- 有效权重只在计算和展示时派生，不回写权重字段。
- 新增计入进度的任务会扩大工作范围，可能导致父级进度下降；系统应记录操作记录并触发重算。

## 任务状态与进度

- 任务主状态：未开始、进行中、已完成、已取消、已作废。
- 任务状态由用户维护，进度变化不自动修改任务状态。
- 叶子任务状态为已完成时，在列表、统计和上级汇总中的有效进度按 `100%` 处理。
- 叶子任务的已完成有效进度规则不适用于父任务。
- 父任务即使状态为已完成，仍展示子任务汇总进度。
- 父任务存在未完成的计入进度子任务时，禁止标记为已完成。
- 已完成父任务禁止新增子任务；如需新增子任务，先改为非完成状态。
- 叶子任务新增第一个计入进度子任务时，应提示当前人工进度将由子任务汇总进度覆盖。
- 父任务恢复为无计入进度子任务的叶子任务时，当前进度恢复为最后一次作为叶子任务时人工填报的进度。
- 页面只展示一个当前进度，不向用户暴露内部人工进度和汇总进度字段差异。
- 已完成任务允许继续编辑普通字段，关键字段变更记录操作记录并触发必要重算。
- 已取消任务可恢复为其他可编辑状态；取消和恢复均要求填写原因。
- 已作废是终态，不允许再编辑任务内容、进度、状态、权重、阻塞等。
- 作废要求填写原因并二次确认。
- 取消、恢复、作废原因保存到状态变更记录或操作记录中，不覆盖历史。

## 阻塞、风险与预警

- 阻塞信息独立于项目、阶段、任务主体信息保存，详细表字段留到概要设计。
- 阻塞对象支持项目、阶段、任务。
- 阻塞类型：外部依赖、内部协作、资源不足、决策待定、环境/系统问题、其他。
- 项目和阶段页面应区分自身阻塞与下级阻塞。
- 阻塞不进入主状态机，不直接改变进度计算。
- 人工风险等级：正常、有风险、已偏离。
- 项目、阶段、任务均支持维护人工风险。
- 人工风险变更要求填写原因并记录操作记录。
- 下级风险不覆盖父级人工风险，只生成系统预警。
- 系统预警类型和口径已确认：已逾期、临近逾期、存在阻塞、下级阻塞、进度滞后、下级风险、里程碑风险。
- 临近逾期默认阈值为 3 天，可后续配置。
- 进度滞后默认阈值为 20 个百分点。
- 预警的数据来源、缓存、快照、冗余字段和定时任务频率留到概要设计阶段。

## 进度驾驶舱

- 进度驾驶舱是查看型页面，不直接编辑项目、阶段或任务。
- 进度驾驶舱保留三块内容：核心指标卡、项目进度概览、风险与阻塞汇总。
- 删除“重点项目跟踪”，避免和项目进度概览、风险与阻塞汇总重复。

### 核心指标卡

- 项目总数：当前用户有权限查看的顶级项目数量。
- 进行中项目数：当前用户有权限查看的顶级项目中，状态为进行中的项目数量。
- 逾期项目数：当前用户有权限查看的顶级项目中，命中已逾期预警的项目数量。
- 风险项目数：当前用户有权限查看的顶级项目中，人工风险为有风险或已偏离，或存在下级风险预警的项目数量。
- 阻塞项目数：当前用户有权限查看的顶级项目中，自身或下级存在未解除阻塞的项目数量。
- 不展示平均进度或整体完成率。

### 项目进度概览

- 口径：当前用户有权限查看的、状态为进行中的顶级项目。
- 展示进度区间柱状图：`0-25%`、`26-50%`、`51-75%`、`76-100%`。
- 展示简洁项目进度列表：项目名称、进度条、进度百分比。
- 不展示项目状态字段。
- 进度条红色：项目命中已逾期预警，或人工风险为已偏离，或存在未解除阻塞。
- 进度条黄色：项目命中临近逾期、进度滞后、下级风险、里程碑风险任一预警，或人工风险为有风险。
- 红色优先于黄色。
- 可展示风险、预警、阻塞三类异常图标。
- 不做悬停复杂提示；点击项目名称、进度条或异常图标均进入项目详情。

### 风险与阻塞汇总

- 采用异常明细视角，不强制按顶级项目聚合。
- 展示三个数字：风险对象数、预警对象数、未解除阻塞数。
- 展示三个图：人工风险分布、系统预警分布、阻塞类型分布。
- 风险对象数：当前用户有权限范围内，人工风险为有风险或已偏离的项目、阶段、任务数量。
- 预警对象数：当前用户有权限范围内，命中任一系统预警的项目、阶段、任务、里程碑数量。
- 未解除阻塞数：当前用户有权限范围内未解除的阻塞记录数量。
- 人工风险分布只展示有风险和已偏离，不展示正常。
- 系统预警分布按已逾期、临近逾期、进度滞后、下级风险、里程碑风险统计。
- 阻塞类型分布按外部依赖、内部协作、资源不足、决策待定、环境/系统问题、其他统计。
- 点击风险、预警或阻塞图表项时，跳转到风险与阻塞菜单下对应列表，并携带对应筛选条件。

## 项目管理菜单

- 项目管理页面采用左右分栏。
- 左侧为可筛选树形项目卡片列表；右侧为当前选中项目详情工作区。
- 项目列表默认展示顶级项目，展开后最多显示到第 3 层。
- 筛选命中子项目时，左侧自动展开所属父级并选中命中项目；右侧展示该项目详情。
- 驾驶舱跳转到项目管理时，通过路由携带筛选条件，左侧展示筛选标签，可单项移除或一键清空。

### 项目列表常驻筛选

| 筛选项 | 控件 | 数据来源 | 约束 |
|---|---|---|---|
| 关键词 | 输入框 | 用户输入 | 支持项目名称、项目编号、负责人搜索；最多 100 字符；带清空按钮 |
| 快捷筛选 | 可选标签/分段按钮 | 系统固定枚举和后端统计口径 | 单选：全部、进行中、风险、阻塞、逾期 |
| 高级筛选入口 | 筛选图标按钮 | 当前筛选状态 | 打开筛选抽屉或浮层 |
| 已选条件 | 筛选标签 | 当前筛选条件 | 支持单项移除和全部清空 |

### 项目列表高级筛选

| 筛选项 | 控件 | 数据来源 | 约束 |
|---|---|---|---|
| 项目状态 | 多选下拉框 | 系统固定整数枚举 | 可选未开始、进行中、已暂停、已完成、已取消、已归档；具体状态矩阵后续确认 |
| 风险等级 | 多选下拉框 | 系统固定整数枚举 | 可选正常、有风险、已偏离 |
| 系统预警 | 多选下拉框 | 系统固定枚举 | 可选已逾期、临近逾期、进度滞后、下级风险、里程碑风险 |
| 阻塞状态 | 单选下拉框 | 系统固定枚举和阻塞记录 | 可选全部、有未解除阻塞、无未解除阻塞、自身阻塞、下级阻塞 |
| 计划完成时间 | 日期范围选择器 | 用户输入 | 只保留开始日期和结束日期，不做今天/本周/本月快捷项 |

### 项目卡片字段

| 字段 | 控件/展示 | 数据来源 | 约束 |
|---|---|---|---|
| 项目名称 | 文本 | 项目表 | 最多显示 2 行；超出省略；点击选中项目 |
| 项目编号 | 辅助文本 | 项目表，系统生成 | 只读展示；不可编辑 |
| 负责人 | 文本 | 项目负责人关联用户 | 只显示姓名；单人；姓名过长单行省略 |
| 项目状态 | 标签 | 系统固定整数枚举 | 仅展示，状态规则后续统一确认 |
| 当前进度 | 进度条 + 百分比 | 后端进度快照 | 0-100 整数；只读；异常颜色按风险/预警/阻塞规则 |
| 风险/预警/阻塞 | 图标或小标签 | 人工风险、系统预警、阻塞记录 | 最多展示风险、预警、阻塞三类；红色优先于黄色 |
| 计划完成时间 | 日期文本 | 项目计划完成时间 | 未填写不展示；逾期时高亮 |
| 子项目数量 | 数字/展开提示 | 后端 `childCount` | 有下级时展示；点击展开/收起 |

不展示项目层级标识；层级只通过树形缩进、连接线、展开/收起关系表达。不提供复制项目编号操作。

### 项目列表操作

| 操作 | 控件 | 数据来源 | 约束 |
|---|---|---|---|
| 新建项目 | 主按钮或卡片更多菜单项 | 系统权限点、点击入口 | 所有创建按钮统一叫新建项目；左侧顶部创建顶级项目；卡片更多菜单创建当前项目下级项目 |
| 刷新列表 | 图标按钮 | 当前筛选条件 | 保留当前筛选和选中态，重新请求列表 |
| 选择项目 | 点击卡片 | 项目列表接口 | 选中后右侧展示该项目详情 |
| 展开/收起子项目 | 展开箭头按钮 | `childCount` / 子项目接口 | 仅有子项目时展示；最多展开到第 3 层 |
| 编辑项目基本信息 | 卡片更多菜单 | 当前项目节点、系统权限点 | 项目负责人及以上角色可见；打开同一编辑表单 |
| 清空当前筛选 | 筛选标签区按钮 | 当前筛选状态 | 仅存在筛选条件时展示；清空后回到默认顶级项目列表 |

完成、取消、归档、删除等高影响项目操作不放在左侧卡片区，后续在操作全集和状态矩阵中统一确认。

### 项目列表排序和空状态

| 项目 | 控件/表现 | 数据来源 | 约束 |
|---|---|---|---|
| 默认排序 | 后端排序 | 项目 `sort_order`、更新时间 | 同级项目按 `sort_order` 升序；无排序值时按更新时间倒序 |
| 搜索结果排序 | 后端排序 | 匹配度、状态、更新时间 | 命中项优先；同级仍保留树形归属 |
| 筛选无结果 | 空状态 | 当前筛选条件 | 显示无匹配项目，提供清空筛选按钮 |
| 无任何项目 | 空状态 | 项目列表接口 | 有创建权限显示新建项目，无权限只显示空提示 |
| 加载更多/分页 | 滚动加载 | 项目列表接口 | 顶级项目分页；子项目按展开节点懒加载 |
| 默认选中 | 自动选中 | 项目列表接口 | 首次进入默认选中第一个顶级项目；筛选后选中第一个命中项目 |

## 项目基础表单

| 字段 | 控件 | 数据来源 | 约束 |
|---|---|---|---|
| 项目名称 | 输入框 | 用户填写 | 必填；最多 100 字符；同一上级项目下不允许重名 |
| 项目编号 | 只读文本 | 后端生成 | 创建后生成；全局唯一；不可编辑 |
| 上级项目 | 只读文本 | 点击入口带入 | 顶级项目显示 `无`；子项目显示上级项目路径；不可编辑 |
| 负责人 | 用户选择器 | 用户/组织接口 | 必填；单选；默认当前用户 |
| 项目成员 | 用户多选器 | 用户/组织接口 | 非必填；负责人自动纳入成员 |
| 计划开始时间 | 日期选择器 | 用户填写 | 非必填；不能晚于计划完成时间 |
| 计划完成时间 | 日期选择器 | 用户填写 | 非必填；不能早于计划开始时间 |
| 项目描述 | 多行文本框 | 用户填写 | 非必填；最多 1000 字符 |

- 新建项目时不手选上级项目，由点击入口决定。
- 编辑项目时不允许调整上级项目。
- 风险等级不放在项目基础信息表单中，后续在风险与阻塞页签维护。
- 项目状态相关操作先后置，等项目页面其他内容确认后再统一决定。

### 项目编号生成规则

| 层级 | 生成规则 | 示例 |
|---|---|---|
| 顶级项目 | `XM` + 创建日期 `yyyyMMdd` + 当日三位流水 | `XM20260608001` |
| 二级项目 | 上级项目编号 + `-` + 同父级两位流水 | `XM20260608001-01` |
| 三级项目 | 上级项目编号 + `-` + 同父级两位流水 | `XM20260608001-01-01` |

- 项目编号后端生成，前端只读展示。
- 项目创建后编号不随项目名称变化。
- 不支持编辑编号。
- 同父级子项目按创建顺序生成 `01`、`02`、`03`。
- 项目最多 3 层，所以编号最多到 `XM20260608001-01-01`。
- 暂不支持移动项目父级，避免破坏编号层级语义。

## 项目详情页签

- 项目详情顶部区域暂不确认，先确认各页签信息后再决定顶部区域最小内容。
- 右侧详情页签当前为：基础信息、阶段与里程碑、任务、风险与阻塞、成员与记录。
- 删除“概览”页签，改为“基础信息”页签；基础信息不查统计数量。
- 删除“子项目”页签，子项目通过左侧项目树表达和进入。

### 基础信息页签

| 信息 | 控件/展示 | 数据来源 | 约束 |
|---|---|---|---|
| 项目名称 | 文本/表单回显 | 项目详情接口 | 必填；最多 100 字符 |
| 项目编号 | 只读文本 | 项目详情接口 | 系统生成；不可编辑 |
| 上级项目 | 只读文本 | 项目详情接口 | 顶级项目显示 `无`；子项目显示上级路径 |
| 负责人 | 文本/用户选择回显 | 项目详情接口 + 用户表关联 | 必填；只显示姓名 |
| 计划开始时间 | 日期文本 | 项目详情接口 | 可为空；不能晚于计划完成时间 |

- 基础信息页签不展示项目成员，成员统一去成员与记录页签。
- 基础信息页签不查询任务数、阶段数、里程碑数、阻塞数、预警数。

- 左侧项目卡片更多菜单也保留编辑项目基本信息的快捷入口。

### 阶段与里程碑页签

- 仅展示当前选中项目节点自身的阶段和里程碑，不包含下级项目。
- 阶段一个列表，里程碑一个列表，不做详情页。
- 阶段和里程碑不支持删除，仅支持作废。
- 阶段和里程碑不支持排序。
- 作废操作放在列表操作项中，必须填写原因并二次确认。
- 阶段列表字段、里程碑列表字段和作废细节继续确认。
