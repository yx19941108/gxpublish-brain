游工，以下为 R5.6 冻结契约修补补丁。

  一、修补结论总览

  - 问题：submitDepartment 缺在新增/修改入参里
  - 当前冻结契约中的现状：DetailVO 已有 submitDepartment，但“新增保存”“修改保存”入参未列出该字段；PRD 与 R4.5 已明确“报
    送部门”为页面字段，且口径为“自动带出、只读”
  - 问题类型：缺项
  - 修补结论：submitDepartment 补入“新增保存”“修改保存”两个入参对象；新增保存中按必填只读字段处理，修改保存中按只读回传
    字段处理，不作为可修改字段
  - 是否已可直接用于第6/7轮开发：是
  - 问题：新增页“提交”动作与后端保存/提交接口的调用编排没有冻结
  - 当前冻结契约中的现状：保存接口、submitAndFlowStart、resubmit 三类接口都已存在，但“新增页点击提交”到底是前端两次调用
    还是后端一次封装，未被单点写死
  - 问题类型：未冻结
  - 修补结论：冻结为单一方案 A：新增页点击“提交”时，前端先调“新增保存”，拿到 id 后再调 submitAndFlowStart；resubmit 继续
    保持独立接口，不复用新增页提交流程
  - 是否已可直接用于第6/7轮开发：是
  - 问题：ResourceItemVO 的真实访问地址字段名没有冻结
  - 当前冻结契约中的现状：ResourceItemVO 目前仅列 externalUrl，并明确写有“附件/视频真实访问地址字段名：白名单不足，需主
    控补充”
  - 问题类型：未冻结
  - 修补结论：白名单足以冻结“附件下载与视频播放共用一个真实访问地址字段、外链继续沿用 externalUrl”这层语义，但不足以定死
    该字段的精确字段名；该字段名仍需主控拍板
  - 是否已可直接用于第6/7轮开发：否
  - 问题：文件所有权矩阵没有细化到目录级，无法安全并行开发
  - 当前冻结契约中的现状：R5.5 只冻结了后端/前端业务范围，没有冻结目录级路径模式
  - 问题类型：未冻结
  - 修补结论：仅凭白名单材料无法安全给出目录级路径模式；该项仍需主控拍板，在补齐前不得启动并行编码
  - 是否已可直接用于第6/7轮开发：否

  二、逐项修补补丁

  【修补项 1：submitDepartment 入参补齐】

  - 修补结论：submitDepartment 是“新增保存”入参必填字段；不是“修改保存”可修改字段，但必须补入“修改保存”入参对象并按只读
    字段处理
  - 应补到：
      - “新增保存”入参对象
      - “修改保存”入参对象
      - 新增页/修改页表单中的“报送部门”字段
      - 字段字典
      - 接口清单
  - 最终口径：页面存在“报送部门”只读字段；新增提交链中的第一步保存必须带 submitDepartment；修改保存也必须带
    submitDepartment，但用户不能改，后端也不得把它当作可编辑业务字段

  【修补项 2：新增页“提交”动作编排冻结】

  - 修补结论：冻结为方案 A
  - 前端调用方式：新增页点击“提交”时，先调用“新增保存”提交完整表单并拿到 id，再调用 POST /workflow/manuscript-review/
    submitAndFlowStart 传 id 发起流程；“再次提交”不走这条链路，仍固定为“修改保存完成并回详情后，再由详情页单独调用 /
    resubmit”
  - 后端接口职责：“新增保存”只负责落单据并返回 id，不负责发起流程；submitAndFlowStart 只负责提交前校验、持证判定、流程发
    起与提交时间写入；/resubmit 只负责被退回后的再次提交
  - 是否影响第6/7轮范围：影响，且本项修补后可直接解锁第6轮后端接口边界与第7轮前端提交链路

  【修补项 3：ResourceItemVO 访问地址字段冻结】

  - 修补结论：白名单只足以冻结语义，不能冻结精确字段名；现阶段只能定死“附件下载地址与视频播放地址共用同一个真实访问地址
    字段，外链继续沿用 externalUrl”，该真实访问地址字段的名字仍需主控拍板
  - ResourceItemVO 最终字段：
      - id
      - resourceType
      - resourceTypeLabel
      - displayName
      - externalUrl
      - createdTime
      - <附件/视频真实访问地址字段名：需主控拍板>
  - 前端依赖字段：资源区中的附件打开/下载与视频播放器都依赖 <附件/视频真实访问地址字段名：需主控拍板>；外链列表依赖
    externalUrl
  - 不得暴露字段：ossId、内部账号字段、租户字段、内部解析参数、引擎原始扩展字段、payloadJson、rawPayload

  【修补项 4：目录级文件所有权矩阵冻结】

  - 后端 agent 可改目录：需主控拍板
  - 前端 agent 可改目录：需主控拍板
  - 双方禁止改动：
      - 当前冻结契约包及本轮 4 份上游白名单文档
      - 任何未被主控显式指派的公共文件
      - 任何超出本轮 4 个缺口之外的文件
  - 共享变更处理规则：凡涉及公共 API 契约、共用读模型/类型、共享跳转参数、共享工作流能力、共享上传基础能力的文件，统一由
    主控串行处理；在目录级矩阵补齐前，不得启动两个 sub agent 并行编码
