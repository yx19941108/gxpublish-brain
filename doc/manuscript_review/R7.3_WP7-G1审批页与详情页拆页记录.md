# R7.3_WP7-G1审批页与详情页拆页记录

## 1. 文档定位

- 本文承接 `R7.2_WP7-G1剩余角色浏览器补证记录.md` 之后的结构性前端收口。
- 本轮不改冻结契约、不改业务动作、不改 shared 输出，只处理“审批页与详情页仍共用同一页面文件，不利于后续维护”的结构问题。
- 本轮目标是：
  - 让详情页和审批页变成两个独立页面文件；
  - 当前页面内容先保持基本一致；
  - 标题和入口语义明确拆开；
  - 回归确认拆页没有破坏现有 `WP7-G1` 行为。

## 2. 本轮目标

1. 把 `/manuscript/review/detail` 和 `/manuscript/review/approval` 从“同一页面文件 + 路由分支模式”拆成两个独立页面文件。
2. 页面内容先继续复用同一套壳，不在本轮扩做新的审批视觉设计。
3. 保持现有业务行为不变，只做结构分离与标题分离。

## 3. 实际修改

### 3.1 页面结构

- 新增共享壳：
  - `plus-ui-ts/src/views/manuscript-review/detail-page-shell.vue`
- 独立详情页入口：
  - `plus-ui-ts/src/views/manuscript-review/detail.vue`
- 独立审批页入口：
  - `plus-ui-ts/src/views/manuscript-review/approval.vue`

### 3.2 路由切换

- 路由 `review/detail` 继续指向 `detail.vue`
- 路由 `review/approval` 改为指向 `approval.vue`

### 3.3 结构收口方式

- 当前“详情页”和“审批页”已经是两个独立页面文件；
- 但内部仍复用 `detail-page-shell.vue` 这一套共享壳；
- 共享壳通过 `page-mode="detail" / "approval"` 切换标题、描述和动作栏模式；
- 这样本轮不改变业务行为，同时已经为后续分别修改两个页面留下独立落点。

## 5. 当前结论

### 5.1 已确认

- 详情页和审批页现在已经拆成两个独立页面文件。
- 当前页面内容仍保持基本一致，没有引入新的业务差异。
- 标题已经按你的要求分离：
  - 详情页：`审校详情`
  - 审批页：`审校审批`
- 本轮拆页没有破坏现有 `WP7-G1` 定向行为。

### 5.2 风险

- 当前只是“页面文件拆开 + 共享壳复用”，不是彻底做成两套完全独立实现。
- 如果后续两页差异继续扩大，下一轮应在此基础上继续拆壳，而不是再回退到同页分支。

### 5.3 推进方案

1. 当前可以把“审批页和详情页结构拆开”这个问题视为已完成。
2. 若后续要继续优化审批页，只需要围绕 `approval.vue` 和 `detail-page-shell.vue` 演进，不必再动详情页入口文件。
