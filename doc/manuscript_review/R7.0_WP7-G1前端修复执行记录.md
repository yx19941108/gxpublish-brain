## 2. 本轮目标

本轮目标不是重开方案，也不是继续做 `WP6-G1` 后端验收，而是基于游工已指出的问题，直接收口 `WP7-G1` 前端页面与冻结契约的偏差，重点覆盖：

1. 列表页查询条件与后端真实值域对齐
2. 删除无数据来源的“媒体栏目”查询项
3. 修正“审批中”等业务状态查询值
4. 把新增页流程类型从手输改为固定选项
5. 去掉“报送部门”必填阻塞
6. 移除详情页调试性展示块
7. 让详情页外链支持点击跳转

## 3. 已确认完成项

### 3.1 列表页

- 流程类型查询值已从前端自造口径收口为后端真实口径：
  - `AUDIT`
  - `PROOFREAD`
- 业务状态查询值已收口为：
  - `WAITING`
  - `BACK`
  - `FINISH`
  - `CANCEL`
  - `REJECT`
- “媒体栏目”查询条件已从搜索区移除。
- 列表表格中的“媒体栏目”列也一并移除，和 `R3_拼装式设计.md` 中“台账字段改为稿件号、标题、流程类型、业务状态、当前节点、发起人、更新时间”的口径保持一致。

### 3.2 新增页 / 修改页

- 新增页流程类型已从自由输入框改为固定下拉框。
- 固定选项仅保留：
  - `审核流程`
  - `校对流程`
- `submitDepartment` 仍保持只读自动带出，但已不再作为必填校验项阻塞提交。
- 新增页和修改页的主动作仍保持冻结口径：
  - 新增页：`提交`
  - 修改页：`保存`

### 3.3 详情页

- 已移除面向用户不应暴露的调试性信息块，包括：
  - `permissionMatrix 动作矩阵`
  - `动作来源：permissionMatrix`
  - `当前节点说明`
  - `按钮分流板`
- 详情页顶部和信息区说明文案已改为业务表达，不再直接暴露实现细节。
- 外链资源已改为 `<a>` 跳转，新窗口打开，并带 `noopener noreferrer`。
