## 3. 每个文件的关键变更摘要

### 3.1 命令模型

- `CreateManuscriptReviewCommand.java`
  - 旧 `content/attachmentCount/externalLinkCount/externalLinkUrls` 写侧语义已清退。
  - 改为冻结写侧字段：`processType/externalManuscriptCode/title/mediaChannel/submitDepartment/authorName/remark/contentBody`。

- `ResubmitManuscriptReviewCommand.java`
  - 旧“再次提交时顺带携带标题/正文/count/URL 列表”的聚合旧语义已清退。
  - 改为只保留 `reviewId`，与冻结后的独立 `/resubmit` 边界一致。

- `UpdateManuscriptReviewCommand.java`
  - 新增私有修改保存模型，用于承载修改页保存，不再硬让旧 `Resubmit` 文件继续扛修改保存语义。

- `AddManuscriptReviewResourceCommand.java`
  - 新增资源追加私有模型，按冻结口径承载 `reviewId/resourceType/displayName/ossId/externalUrl`。

- `DisableManuscriptReviewResourceCommand.java`
  - 新增资源停用私有模型，承载 `resourceId/disabledReason`。

- `AddManuscriptReviewVideoMarkCommand.java`
  - 新增视频标注私有模型，承载 `reviewId/resourceId/startTimeText/endTimeText/markContent`。

### 3.2 当前用户网关

- `ManuscriptReviewCurrentUserGateway.java`
  - 从只暴露 `currentUserId` 扩展为同时暴露 `tenantId/deptId/username`，避免写侧再去走旧别名列或静态工具绕回旧实现。

- `LoginHelperCurrentUserGateway.java`
  - 对应实现补齐 `tenantId/deptId/username` 读取。

### 3.3 主表实体与写服务

- `ManuscriptReviewRecordEntity.java`
  - 新增冻结写侧字段：`mediaChannel`、`submitDepartment`、`authorName`、`remarkText`、`contentBody`、`firstSubmitTime`、`latestSubmitTime`。
  - 旧 `content/note/mediaChannelLabel/submitterDeptName/authorNames` 继续保留，仅作为读侧兼容残留，不再作为新写侧依据。

- `ManuscriptReviewService.java`
  - 旧 `createAndSubmit` 聚合提交流程语义已被净替换，重写为 B1 私有写服务：
    - `create`
    - `update`
    - `submitAndFlowStart`
    - `resubmit`
    - `addResource`
    - `disableResource`
    - `addVideoMark`
  - 新增主单校验：
    - `externalManuscriptCode` 非空时模块内唯一
    - `title <= 200`
    - `mediaChannel <= 100`
    - `submitDepartment <= 100`
    - `authorName <= 200` 且只允许中文顿号 `、`
    - `remark <= 1000`
    - `contentBody <= 20000`
  - 新增 `submitDepartment` 只读回传约束：修改保存时若与已存值不一致，直接拦截。
  - 新增提交流转前的 B1 闭环：
    - `submitAndFlowStart` 生成系统稿件号
    - 首次提交写 `firstSubmitTime/latestSubmitTime`
    - 再次提交只刷新 `latestSubmitTime`
    - 提交前合并校验附件/外链/视频三类有效资源至少一种
  - 新增资源闭环：
    - 资源追加只插入新行，不覆盖旧行
    - 资源停用只改 `enabled/disabledBy/disabledTime`
    - 外链 URL 校验 `http/https`、`<=500`、同流程不重复
    - 视频资源走独立 `resourceType=VIDEO` 分支，不再用旧 count 语义处理
  - 新增视频标注闭环：
    - 接受 `ss/mm:ss/HH:mm:ss`
    - 统一归一为 `HH:mm:ss`
    - 同步落 `startSeconds/endSeconds`
    - 非法格式、结束早于开始、超出视频总时长、视频总时长缺失一律拦截
