 游工，

  一、后端最小闭环范围

  - 必做接口：
  - GET /workflow/manuscript-review/list
  - GET /workflow/manuscript-review/{id}
  - POST /workflow/manuscript-review
  - PUT /workflow/manuscript-review
  - POST /workflow/manuscript-review/submitAndFlowStart
  - POST /workflow/manuscript-review/resubmit
  - PUT /workflow/manuscript-review/cancelProcessApply
  - POST /workflow/manuscript-review/resource
  - PUT /workflow/manuscript-review/resource/disable
  - POST /workflow/manuscript-review/video-mark
  - 必做能力：
  - 主单关键字段与校验闭环：系统稿件号生成、外部稿件编号填写后全局唯一、标题/正文/说明/作者/外链长度校验、作者分隔符校
    验、同流程 URL 去重、附件或外链至少一种、视频计入附件。
  - 流程闭环：普通三级串行、持证发起人首提跳过一级、退回后修改再提、发起人撤销、三级驳回终止。
  - 详情聚合闭环：详情一次返回基本信息、当前有效资源、当前选中视频有效标注、自然语言时间线、permissionMatrix。
  - 资源闭环：资源只追加、不覆盖；资源停用后退出当前有效区但仍可追溯。
  - 时间闭环：标注时间支持 ss / mm:ss / HH:mm:ss，统一归一为 HH:mm:ss；非法格式、结束早于开始、超出总时长、总时长未识别
    全部拦截。
  - 展示闭环：后端输出业务文案读模型与脱敏结果；权限布尔值只出现在详情 permissionMatrix。
  - 先不做：
  - 审批链独立持久化模型与独立 CRUD 接口。
  - 详情页内直接完成审批、退回、驳回。
  - 列表接口下沉任何权限布尔值。
  - 独立时间线查询接口的第 6/7 轮必须闭环证明。
  - 视频标注停用动作的第 6/7 轮必须闭环证明。
  - 保存接口不等于草稿能力；本轮不引入草稿。

  二、前端最小闭环范围

  - 必做页面：
  - 列表页。
  - 新增页。
  - 修改页。
  - 详情页。
  - 必做能力：
  - 列表页只承担搜索、排序、状态查看、进入详情；行内默认且唯一动作为“详情”。
  - 新增页只提供提交，不提供草稿。
  - 修改页承担资料修改、资源追加、资源停用；保存后回详情。
  - 详情页承担动作中枢：状态摘要、基本信息、当前有效资源、自然语言时间线、按钮分流。
  - 详情页按钮只按 DetailVO.permissionMatrix 渲染，不允许前端本地猜 isCurrentApprover。
  - 当前审批人只显示“修改 / 去审批 / 返回”。
  - 被退回发起人只显示“修改 / 再次提交 / 返回”。
  - 纯查看人只显示“返回”。
  - 多视频采用“视频列表 + 单播放器”；标注按开始时间正序；点击标注跳转开始时间。
  - 所有展示只用业务文案，不裸露主键、账号、租户、内部标识、原始技术码值。
  - 先不做：
  - 列表页出现“修改 / 再次提交 / 撤销 / 去审批”行内动作。
  - 详情页内直接审批、退回、驳回。
  - 独立的业务待办页、已办页。
  - 视频标注停用作为第 7 轮最小闭环必做项。

  三、冻结接口契约

  1. 列表查询

  - 接口名称：审校流程单分页列表
  - 方法：GET
  - 路径：/workflow/manuscript-review/list
  - 入参字段：keyword、processType、mediaChannel、businessStatus、currentNodeCode、startTimeFrom、startTimeTo、pageNum、
    pageSize
  - 出参字段：total、rows: ListItemVO[]
  - 调用方页面：列表页
  - 是否 P0：是

  2. 详情查询

  - 接口名称：审校流程单详情聚合
  - 方法：GET
  - 路径：/workflow/manuscript-review/{id}
  - 入参字段：id
  - 出参字段：DetailVO
  - 调用方页面：详情页、修改页初始化
  - 是否 P0：是

  3. 新增保存

  - 接口名称：审校流程单新增保存
  - 方法：POST
  - 路径：/workflow/manuscript-review
  - 入参字段：processType、externalManuscriptCode、title、mediaChannel、authorName、remark、contentBody
  - 出参字段：id
  - 调用方页面：新增页内部保存步骤
  - 是否 P0：是

  4. 修改保存

  - 接口名称：审校流程单修改保存
  - 方法：PUT
  - 路径：/workflow/manuscript-review
  - 入参字段：id、processType、externalManuscriptCode、title、mediaChannel、authorName、remark、contentBody
  - 出参字段：无
  - 调用方页面：修改页
  - 是否 P0：是

  5. 提交发起

  - 接口名称：审校流程单提交并发起流程
  - 方法：POST
  - 路径：/workflow/manuscript-review/submitAndFlowStart
  - 入参字段：id
  - 出参字段：DetailVO
  - 调用方页面：新增页
  - 是否 P0：是

  6. 再次提交

  - 接口名称：审校流程单再次提交
  - 方法：POST
  - 路径：/workflow/manuscript-review/resubmit
  - 入参字段：id
  - 出参字段：DetailVO
  - 调用方页面：详情页
  - 是否 P0：是

  7. 撤销

  - 接口名称：审校流程单撤销
  - 方法：PUT
  - 路径：/workflow/manuscript-review/cancelProcessApply
  - 入参字段：id、reason
  - 出参字段：无
  - 调用方页面：详情页
  - 是否 P0：是

  8. 资源新增

  - 接口名称：审校流程资源新增
  - 方法：POST
  - 路径：/workflow/manuscript-review/resource
  - 入参字段：reviewId、resourceType、displayName、ossId、externalUrl
  - 出参字段：ResourceItemVO
  - 调用方页面：修改页
  - 是否 P0：是

  9. 资源停用

  - 接口名称：审校流程资源停用
  - 方法：PUT
  - 路径：/workflow/manuscript-review/resource/disable
  - 入参字段：resourceId、disabledReason
  - 出参字段：无
  - 调用方页面：修改页
  - 是否 P0：是

  10. 视频标注新增

  - 接口名称：审校流程视频标注新增
  - 方法：POST
  - 路径：/workflow/manuscript-review/video-mark
  - 入参字段：reviewId、resourceId、startTimeText、endTimeText、markContent
  - 出参字段：VideoMarkItemVO
  - 调用方页面：详情页
  - 是否 P0：是

  四、冻结字段字典

  - ListItemVO：id、processType、processTypeLabel、manuscriptCode、title、mediaChannel、businessStatus、
    businessStatusLabel、currentNodeCode、currentNodeLabel、initiatorName、updateTime
  - DetailVO：id、processType、processTypeLabel、manuscriptCode、externalManuscriptCode、title、mediaChannel、
    submitDepartment、authorName、remark、contentBody、contentSummary、businessStatus、businessStatusLabel、
    currentNodeCode、currentNodeLabel、initiatorName、firstSubmitTime、latestSubmitTime、updateTime、attachmentList、
    externalLinkList、videoList、videoMarkList、timelineItems、permissionMatrix
  - PermissionMatrixVO：isInitiator、isCurrentApprover、isHistoryParticipant、canView、canEdit、canResubmit、canCancel、
    canGotoApproval、buttonReason
  - TimelineItemVO：eventTime、eventType、eventTypeLabel、eventCode、eventText、operatorName、relatedNode、
    relatedResourceName、statusLabel、diffSummary
  - ResourceItemVO：id、resourceType、resourceTypeLabel、displayName、externalUrl、createdTime
  - ResourceItemVO 中附件/视频真实访问地址字段名：白名单不足，需主控补充
  - VideoMarkItemVO：id、startTimeText、endTimeText、markContent

  五、冻结口径

  - businessStatus 码值与文案：
  - WAITING = 审批中
  - BACK = 已退回
  - FINISH = 已完成
  - CANCEL = 已取消
  - REJECT = 已驳回
  - currentNodeLabel 业务文案：
  - 待一级审批
  - 待二级审批
  - 待三级审批
  - 待发起人处理
  - 流程完成
  - 流程已取消
  - 流程已驳回
  - 冗余读模型：
  - processTypeLabel
  - businessStatusLabel
  - currentNodeLabel
  - contentSummary
  - attachmentList
  - externalLinkList
  - videoList
  - videoMarkList
  - timelineItems
  - diffSummary
  - permissionMatrix
  - buttonReason
  - 全部权限布尔值
  - 哪些字段不能持久化：
  - 全部 *Label
  - contentSummary
  - attachmentList
  - externalLinkList
  - videoList
  - videoMarkList
  - timelineItems
  - diffSummary
  - permissionMatrix
  - 全部权限布尔值
  - buttonReason
  - 历史参与人判定结果
  - 持证资格判定结果
  - 任何跳转路径与跳转参数
  - 哪些字段不能暴露前端：
  - 用户 ID
  - 账号字段
  - 租户 ID
  - 审批链内部引用值
  - 引擎原始任务字段展示态
  - 引擎原始实例字段展示态
  - 引擎原始扩展字段
  - payloadJson
  - rawPayload
  - operatorId
  - 内部解析参数
  - 列表页动作边界：
  - 列表默认且唯一行内动作为“详情”
  - 列表不承载“修改 / 再次提交 / 撤销 / 去审批”
  - 详情页动作边界：
  - 当前审批人：修改 / 去审批 / 返回
  - 被退回发起人：修改 / 再次提交 / 返回
  - 纯查看人：返回
  - 发起人撤销只允许在“审批中且当前用户为发起人”时出现
  - 审批通过、退回、驳回不在详情页完成，统一在 BPM 办理页完成
  - isCurrentApprover / canEdit / canCancel / canResubmit / canGotoApproval 的唯一来源：
  - 唯一来源为 DetailVO.permissionMatrix
  - 列表 VO 不下沉这五个字段
  - 前端不允许本地推断这五个字段

  六、文件所有权矩阵

  - 后端 agent 允许改哪些目录：白名单不足，需主控补充具体目录；当前只冻结后端业务范围为“主单、提交流转、退回重提、撤销、
    资源追加与停用、标注新增、详情聚合、时间线聚合、脱敏输出、升级脚本”
  - 前端 agent 允许改哪些目录：白名单不足，需主控补充具体目录；当前只冻结前端业务范围为“列表、新增、修改、详情、资源区、
    视频区、时间线、业务 API、VO 类型、按钮分流”
  - 双方都禁止改哪些公共文件：白名单不足，需主控补充具体公共文件；当前冻结为“共享审批办理能力、共享轻量配置能力、共享上
    传基础能力、共享工作流公共逻辑”均不得被本轮业务直接改写

  七、本轮不做清单

  - 草稿能力
  - 删除能力
  - 回收站与恢复
  - 会签、并行审批、加签、减签、转办
  - 动态审批层级
  - 主数据系统对接
  - Office 在线预览
  - 外链联网可达性探测
  - 列表页多动作入口
  - 详情页内直接审批、退回、驳回
  - 审批链独立持久化模型与独立业务 CRUD
  - 列表接口下沉权限布尔值
  - 前端本地推断审批权限
  - 视频标注停用作为第 6/7 轮最小闭环必须项
  - 独立时间线查询接口作为第 6/7 轮最小闭环必须项
