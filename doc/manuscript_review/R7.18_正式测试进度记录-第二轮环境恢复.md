## 2. 本轮开始时的真实状态

1. 非交互 shell 下直接执行：
   - `node -v`
   - `npm -v`

   均报 `command not found`。
2. 按机器基线补查后确认：
   - `Node.js`、`npm`、`Maven`、`JDK` 实际都已安装。
   - 根因是当前非交互 shell 未自动激活 `mise`，不是机器缺少工具。

## 3. 本轮恢复动作与结果

### 3.1 后端恢复

1. 使用 `JDK17 + Maven` 对 `Brain` 执行：
   - `mvn -pl brain-admin -am package -DskipTests`
2. 构建成功，产物为：
   - `Brain/brain-admin/target/brain-admin.jar`
3. 之后直接运行：
   - `java -jar Brain/brain-admin/target/brain-admin.jar`
4. 启动日志命中：
   - `Starting ProtocolHandler ["http-nio-9888"]`
   - `Started BrainApplication`
   - `brain启动成功`
5. 健康检查结果：
   - `GET http://127.0.0.1:9888/auth/code -> HTTP 200`

补充事实：

1. 启动期间可正常连接本地 MySQL 与 Redis。
2. `snail-job` 与 `spring-boot-admin` 有外部连接报错日志，但不阻断 `9888` 主服务启动。

### 3.2 前端恢复

1. 初次执行 `npm run dev` 失败，直接原因：
   - `vite: not found`
2. 进一步确认：
   - `plus-ui-ts/node_modules/.bin/vite` 不存在。
   - 仓库原本没有 `package-lock.json`。
3. 经游工确认后执行：
   - `cd plus-ui-ts && npm install`
4. 首轮安装失败，错误为：
   - `ECONNRESET`
   - 目标包：`@playwright/test`
5. 在更稳定网络权限下重试 `npm install` 后成功，结果为：
   - `added 580 packages`
   - `audited 581 packages`
6. 之后执行：
   - `npm run dev -- --host 127.0.0.1 --port 9999`
7. Vite 控制台命中：
   - `VITE v6.4.1 ready`
   - `Local: http://127.0.0.1:9999/`

补充事实：

1. 对 `9999` 执行 `HEAD /` 出现超时，不作为不可用结论。
2. 改用 `GET /` 取首页后结果为：
   - `HTTP 200`
   - 响应体大小 `4245` bytes
