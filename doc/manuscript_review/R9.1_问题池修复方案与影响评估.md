### 3.1 影响面评分

1. `1`：单页面、单组件、纯展示
2. `2`：单业务链路、多组件

### 问题 4：上传大文件无进度反馈，也无页面级阻断

#### 当前状态

1. 只有 `beforeUpload / onSuccess / onError`。
2. 提交按钮与返回按钮在上传中仍可操作。

#### 涉及文件

2. [form-layout.spec.ts](C:\kuguaHome\project\gxpublish-brain\plus-ui-ts\src\views\manuscript-review\form-layout.spec.ts)

#### 修复方案

1. 前端增加上传中的文件级进度条。
2. 增加页面级 `uploadingCount`，上传未结束时：
   - 禁用主按钮
   - 禁用删除本次上传项
   - 返回时给出二次确认
3. 若当前 `el-upload action` 不便注入进度，可切换为 `http-request` 自定义上传。

#### 伪代码

```ts
const uploadingCount = ref(0)
const uploadProgressMap = ref<Record<string, number>>({})

const customUpload = async (option) => {
  uploadingCount.value += 1
  try {
    await uploadApi(option.file, {
      onProgress: (percent) => uploadProgressMap.value[option.file.uid] = percent
    })
  } finally {
    uploadingCount.value -= 1
  }
}

const canSubmit = computed(() => uploadingCount.value === 0 && !submitting.value)
```
