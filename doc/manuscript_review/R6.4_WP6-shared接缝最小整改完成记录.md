## 4. 关键整改结果

### 4.1 shared 写接口接缝

- `ManuscriptReviewApiController` 已从纯 stub 改为真实接缝层：
  - `POST /workflow/manuscript-review`
  - `PUT /workflow/manuscript-review`
  - `POST /workflow/manuscript-review/submitAndFlowStart`
  - `POST /workflow/manuscript-review/resubmit`
  - `PUT /workflow/manuscript-review/cancelProcessApply`
  - `POST /workflow/manuscript-review/resource`
  - `PUT /workflow/manuscript-review/resource/disable`
  - `POST /workflow/manuscript-review/video-mark`
- shared controller 已正式接到当前 private 写服务，不再返回 `unsupportedContract(...)`
- controller 通过 setter 注入方式显式依赖：
  - `ManuscriptReviewService`
  - `ManuscriptReviewReadableService`
- `ManuscriptReviewService` 已补 `@Service`，写服务装配不再只停留在 `@ConditionalOnBean` 门槛外

### 4.2 shared 列表契约接缝

- `GET /workflow/manuscript-review/list` 现在返回 `TableDataInfo<ManuscriptReviewLedgerItemResponse>`
- shared list 已按冻结字段过滤：
  - `keyword`
  - `processType`
  - `mediaChannel`
  - `businessStatus`
  - `currentNodeCode`
  - `startTimeFrom`
  - `startTimeTo`
  - `pageNum`
  - `pageSize`
- shared list 已改回冻结分页结构：
  - `total`
  - `rows`
- `businessStatus/currentNodeCode` 的过滤和出参不再由旧 `label` 列直接回落驱动，而是按业务码值映射：
  - `审批中 -> WAITING`
  - `已退回 -> BACK`
  - `已完成/流程完成 -> FINISH`
  - `已取消/流程已取消 -> CANCEL`
  - `已驳回/流程已驳回 -> REJECT`

### 4.3 shared 详情读模型接缝

- shared detail 已改为 flat `DetailVO` 风格输出，不再依赖旧 `summaryCard/manuscriptCard/actionBar/resources` 内部结构对外暴露
- shared detail 主链现在优先消费当前新写侧字段：
  - `mediaChannel`
  - `submitDepartment`
  - `authorName`
  - `remarkText`
  - `contentBody`
  - `firstSubmitTime`
  - `latestSubmitTime`
- shared detail 不再把以下旧兼容列当主链事实源：
  - `media_channel_label`
  - `submitter_dept_name`
  - `author_names`
  - `note`
  - `content`
- 当前有效资源区只返回有效资源：
  - `attachmentList`
  - `externalLinkList`
  - `videoList`
  - `videoMarkList`
- `permissionMatrix` 继续只出现在详情，不向列表下沉

### 4.4 边界补齐

- 本轮补了 shared 撤销最小边界：
  - 仅发起人本人可撤销
  - 仅“审批中”流程可撤销
  - shared 层改写到 `已取消 / 流程已取消`
- 本轮没有把以上边界扩写成 BPM 深层闭环，也没有宣称 `WP6-B2` 完成
