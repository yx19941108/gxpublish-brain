  四、状态与节点设计

  1. 资源如何新增（追加）

  - 所有资源新增都插入新记录，不更新旧记录
  - 附件/视频保存 OSS 标识，外链保存 URL，视频标注单独插入记录
  - 依据 doc/manuscript_review/R1_需求拆解结论.md:78、doc/manuscript_review/R1_需求拆解结论.md:80
  - 现成模式：

  - 标注：

  2. 资源如何停用

  - 停用不是删除记录，而是更新该资源记录 status=DISABLED，写停用人、停用时间、停用原因
  - 同时写一条业务时间线事件
  - 依据 doc/manuscript_review/R1_需求拆解结论.md:79
  - 现成模式：
      - 没有现成“资源停用”业务模式
  - 标注：
      - 无证据新设计

  3. 当前资源如何查询

  - 查询条件：reviewId + status=ACTIVE
  - 展示层按资源类型分组：附件、外链、视频、标注
  - 附件与视频通过 OSS ID 批量回查文件信息
  - 依据 doc/manuscript_review/R1_需求拆解结论.md:100、plus-ui-ts/src/components/FileUpload/index.vue:96
  - 现成模式：
      - OSS 反查有证据
      - “当前有效资源”查询口径无现成业务接口，无证据新设计

  4. 历史资源如何保留

  - 所有记录永久保留
  - 历史查询不按 status=ACTIVE 过滤
  - 历史时间线引用资源快照文案而不是只显示技术 ID
  - 依据 doc/manuscript_review/R1_需求拆解结论.md:79、doc/manuscript_review/R1_需求拆解结论.md:89
  - 现成模式：
