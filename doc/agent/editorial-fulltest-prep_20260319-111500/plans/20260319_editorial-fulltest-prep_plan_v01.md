## 9. 风险与阻断判定

### 9.1 阻断项

出现以下任一情况，按阻断处理：

1. 登录态无法建立
2. 主入口 `/workflow/editorial/review` 无法进入
3. 上传完成链 `finish` 失败
4. 审批状态未按 `10 -> 20 -> 30 -> 40` 推进
5. 退回后不能重新编辑或再次提交失败
6. 撤销、终止状态与页面 / 接口 / 数据库不一致
7. 关键角色出现越权可见或越权操作

### 9.2 非阻断项

以下问题本轮默认记为非阻断，但必须单独登记：

1. `user.name` / `dept.name` 展示为空
2. 个别历史 `operateType` 文本乱码
3. 局部文案或展示样式不完整，但不影响主链执行与证据判定
